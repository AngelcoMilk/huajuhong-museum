> 现状：A 线七爪已实现（`src/world/peel.ts` 等）。本文件覆盖剩余的 **五爪、圆果/压果/压果片、橘红胎** 三条变体。

## 0. 总览：四条线共用前五道

四条产品线在前五道工序**完全共用**，第六道才分叉。这是整个扩展的技术基础——不需要重建场景，只需要在第 6 道接不同的动作。

```
采摘 → 分级 → 清洗 → 杀青(80–90℃) → 沥干
                                        │
        ┌───────────────┬───────────────┼───────────────┐
        │               │               │               │
   A 割 5/7 瓣      B 整果压制       C 不处理        (D 取成品)
        │               │               │
   去瓤 → 压形       压扁成形        整只烘干
        │               │               │
   干燥 → 修边       二次压 + 二次烘    橘红胎 / 橘红珠
        │               │
   捆扎 → 七爪/五爪   切片 → 压果片
```

**分级决定走向**（企业工艺口径，非药典，★中）：

| 鲜果重量 | 走向 | 产物 |
|---|---|---|
| < 150 g | C 线 | 橘红胎 |
| 150–230 g | C 线变体 | 橘红珠 |
| > 230 g | A 线或 B 线 | 七爪/五爪 或 圆果/压果片 |

> ⚠️ 常见错误：以为小果做压果片。**错。压果片来自大果，小果只做橘红胎和橘红珠。**

## 1. 变体一：五爪

**与七爪的唯一差别是瓣数。**

| 项 | 七爪（已实现） | 五爪（待做） |
|---|---|---|
| 瓣数 N | 7 | **5** |
| 每瓣角 | 51.43° | **72°** |
| 割刀数 | 7 刀 | 5 刀 |
| 其余全部 | — | 完全相同 |

### 建模落点

`src/world/peel.ts` 里 `PEEL` 常量已经是参数化的：

```js
export const PEEL = {
  R: 3.8,               // 鲜果半径（厘米）
  N: 7,                 // ← 改 5 即五爪
  NS: 72, NV: 20,
  ALPHA_C: Math.PI / 4, // 留着不切的那 1/4（从蒂量起）
  TH0: 1.0,             // 刮之前的皮厚（含白瓤）
  TH1: 0.34,            // 刮好以后
  GAP: 0.03,            // 切口两边各缩回的角度
}
```

改成 5 后，`DTH = 2π/N` 自动变成 72°，其余几何逻辑不用动。

### 成品与捆扎（五爪也是十片一扎）

**结论：五爪一样是「十片一扎、红头绳捆」，成品名就叫「大五爪」。**（★中）

依据原文（07 文档·压平条目）：

> 七裂者对折，呈交错的 V 字形；五裂者把裂片先端向内折回约 3 mm，呈截角五瓣花状；压平后再晒干，**每 10 片扎成 1 把**，即成"**大五爪**""七爪红"。
>
> 这句只说了第一步。成品照片显示后面还要再整片对折，见下面「形状」一节的修正。

- 「大五爪」= 五爪成品的商品名，明确出现在"十片一扎"之后
- 红头绳是打包环节的通用做法（"木板压实后十片一扎，用红头绳"），不按品种区分
- 另有出口规格：**50 片一扎、宽 12 cm**
- 因为每瓣更宽，同样十片一扎，五爪那一把会比七爪宽——"大五爪"的"大"很可能就来自这里（推演，不是原文）

### 史料

- 七爪是贡品制式，价最高；五爪民间常用（★中）
- 同一台切瓣机改传动比即可切换七爪/五爪（专利 CN202210330144 的 1/7 圈传动比）
- 药典原文：割成 **5 或 7 瓣**，两者都是法定形态

### 形状（五爪与七爪的关键差异）

- 展开：五角星形
- **对折是两步，不是一步：**
  1. 先把裂片**瓣尖向内折回约 3 mm**（07 文档的说法）
  2. **再整片对折**，两边的瓣错开
- 结果：一扎十片都是**对折的扇形**，深灰外皮与白色内面一瓣一瓣交替
- **「截角五瓣花、不整片对折」的旧理解已被成品照片推翻**（2026-10-21 用户提供）：07 文档只写了瓣尖内折那一步，后面的整片对折没写
- 捆法：红头绳从根部的结出发，**顺着每一瓣拉出去**，不是十字捆
- 所以五爪不是「七爪少两瓣」，折法和捆法都要单独做
- 尺寸：展平直径按 **12–18 cm** 画（药典 15–28 cm 是上限描述）

## 2. 变体二：圆果 / 压果 / 压果片

这条线内部还有三个不同形态，注意别混。

### 2.1 圆果（原果）

**整果烘干，不割瓣、不压。**

工序：采摘 → 分级 → 清洗 → 杀青 → 沥干 → **整果直接烘干**

- 干燥：按果径分档，**约 4 天/批**，水分 **<13%**
- 形态：完整干果，青褐转黄褐，披白绒毛
- 用途：可整果陈化三年以上，用时再切皮（陈年橘红）

### 2.2 压果

**整果烘软后压扁，套进竹筒定型成圆柱（产地实拍）。**

工序：杀青 → 小火烘软（缩小一大半、变皱）→ **木压果器压扁** → **套进竹筒定型** → 竹筒进竹篮、盖竹罩继续烘 → 木棍顶出圆柱

- 压制方式：**带长柄的木压果器**，把皱缩的小球压成椭圆；压后趁软塞进竹筒
- 形态：**毛绒圆柱**，黄褐细绒、两端圆钝，实拍字幕说「长得像鹿茸」（官网原文：整果烘干是圆果，压扁成形是压果）
- ✅ 更正：此前写的「个人工具做不到圆柱」是错的，手工用竹筒就能定型成圆柱
- 压制时长：无记载，动画里只表现压扁，不写时长

### 2.3 压果片

**把压果切成圆片。**

- 厚度：**2–4 mm**
- 个人做法：**手工刀切**（菜刀或中药切药刀），照药典炮制「切丝或块」的做法
- 形态：**厚实的小圆片**（原料是竹筒定型的圆柱），直径约 2～3 厘米，边缘略不规则，个别有缺口和径向裂纹；外皮一圈深墨绿到近黑，切面由外向内深褐、茶褐、琥珀黄，正中一小团纤维芯

### 建模要点

需要新增两样，都是家常物件：

1. **木压果器、竹筒、竹罩、顶棍**——压板压住皱缩的果，果子塞进竹筒，竹筒竖在竹筛上盖竹罩烘，再用木棍顶出圆柱
2. **一把手工刀**——切片时逐片切下，薄片依次生成并位移

不用建模具，不用液压结构。

### 史料

- 圆果 = 整果烘干；压果 = 压扁成形（官网口径）
- 压果、圆果片是**市场主流**（比七爪产量大得多）
- 古法压多久无记载；传统多描述压到定型或压一夜
- 工业线才用模具压圆柱 + 切片机切圆片，**那两个不进古法线**

## 3. 变体三：橘红胎 / 橘红珠

### 原料

- **橘红胎**：生理落果、疏下来的幼果，**<150 g**
- **橘红珠**：中等幼果，**150–230 g**
- 2021 年收载为广东省中药材标准品种
- ⚠️ 药典"化橘红"特指**外层果皮**，橘红胎是**整果**，二者不是一回事

### 工艺（★高，2006 年地理标志公告）

**两条并存的法：**

甲：沸水汤漂后烘干
乙：直接高温烘干，**80–90℃**

**整果，不割不压。**

这条线的动画价值在于「最简单的工艺」——什么都不做，只烘。正好和七爪的繁复形成对照。

### 形态参数（★高，《化州县志》）

> 正毛橘红胎"圆球形或近似圆球柱形，直径约 **1–5 cm**，表面青褐色或黄棕色，披白色密绒毛，果蒂明显，顶部稍凹，质地干燥坚实，不易剖开"

建模要点：

- 几何：球体或近球柱，直径 1–5 cm（对比鲜果半径 3.8 cm，胎果要小一个量级）
- 绒毛：**灰白／银白短密**，干后偏黄白。**不要画金色长毛**
- 果蒂：明显
- 顶部：稍凹
- 不割不压，所以**不需要 peel.ts 的形变逻辑**，只需要材质 + 绒毛着色器

### 干燥

整果按果径分档，**约 4 天/批**，水分 **<13%**

### 4.5.3 为什么不用工业设备

| 工业设备 | 为什么不进这个动画 |
|---|---|
| 液压压果机 | 整台要配液压站，院子里放不下，也不是一个人能操作的 |
| 七爪切瓣机 | 商品机约 7.8 万元一台，齿轮分度结构复杂，跟"手上功夫"的叙事冲突 |
| 旋挖去囊机 | 尚未商品化，市面上买不到 |
| 连续式漂烫线 / 热泵烘房 | 车间级设备 |

这些在 `knowledge/wiki/机器清单.md` 里有完整机构记录，**留作展厅板块或工业化对比片的素材，不进古法线**。

> 补充一条真实细节：B 站实拍（BV1Ju4y1U7M2）里，个人作坊的实际顺序是
> 烘干 → 软化揉搓推平 → **剪刀修剪** → **压面机压** → 摊平再烘 → 翘起的再软化复压 → 红绳捆扎
> 「压面机」就是家用那种，能直接进场景。

## 7. 资料边界与存疑（重要）

### 7.1 原始资料本身就缺的，不是整理遗漏

传统器具在全部资料里一共只提到 **13 种**，而且**没有一种写了尺寸或形制，也没有图**：

沸水锅、割瓣刀、手持弧形铲、木板、竹筛、簸箕、灶炉、荔枝木焙火、陶缸、麻袋、竹竿、竹篓、箩筐、竹笠

知识库明确写"没有"的东西：
- 锅（镬）的形制
- **传统压模**
- 竹匾
- 晒场用具
- 焙房的结构和尺寸
- 回润用什么器具

所以工具那部分，**形制只能按功能推演**，代码里做成合理的样子即可，不用去追"考据正确"，因为原始资料没给。

### 7.2 三条变体各自的存疑

**五爪**
- 对折形态：**先瓣尖内折约 3 mm，再整片对折成扇形**（成品照片实证）；07 文档只写了第一步，漏了整片对折
- 没有五爪的实物参考图，只有七爪的

**圆果 / 压果 / 压果片**
- 「压多久」无记载：传统说法"压到定型／压一夜"
- 圆果、压果的**成品尺寸无任何资料**，只知道"压成圆柱"和"切片 2–4 mm"
- ⚠️ **历史背景要交代**：1980 年代分户承包后才普及到一家一户；资料原文说"过去各家各户自己压果卖，工艺乱、卖不上价"，现在多由合作社和企业加工。所以"院里自己压果"放在 1980 年代之后才说得通
- 压果在产地实拍里是压扁后用竹筒定型成圆柱；其他作坊是否都这样做，资料没写死

**橘红胎 / 橘红珠**
- **杀青方式有两条并存法**（2006 年公告）：沸水汤漂后烘干 / 直接 80–90℃ 高温烘干。**不要写成唯一法**
- 古法晒或焙要多久：无记载（现代整果烘干约 4 天/批）
- 橘红胎与橘红珠除大小外，工艺是否有别：资料没说

### 7.3 其他存疑

- **采果时间**：两说冲突——记者见闻说"凌晨一两点打手电收果"，传承人口述说"午后露水干透再采，否则绒毛少"。**别合成一条**
- **去瓤工具**："铜铲／弧形去瓤刀"查无出处；06 文档写"手持弧形铲"，07 文档又说查无出处——两处不一致，按推演处理
- **古法最后一步**：药典是"再焙干"，官网有一处写"竹筛阴干"，两说并列，别合并
- **"每个压 99 下"是营销话术**，不要写进动画
- **80–90℃ 是杀青，烘干是 45–70℃**，别混

### 7.4 资料里有明确依据、可以放心用的

- 药典顺序：先沸水略烫 → 再割 5 或 7 瓣 → 去瓤 → 压制成形 → 干燥
- 割瓣：从果顶开刀，往下切至 3/4 收刀（2006 年公告原文）
- 五爪对折：先瓣尖内折约 3 mm，再整片对折成扇形，十片正反面交替
- 七爪对折：交错 V 字形
- 橘红胎形态：直径 1–5 cm，青褐或黄棕，密披白色绒毛，果蒂明显，顶部稍凹
- 分级：<150 g 胎，150–230 g 珠，>230 g 割瓣
- 出成率：100 斤鲜果 → 18–20 斤干果 / 4–5 斤干皮

### 7.5 建模难度判断（摘自 06 文档，方向一致）

- 形状都简单，能直接代码生成：转出来的（锅、陶缸、竹筛、簸箕、箩筐、水盆）、挤出来的（刀、铲、木板、扁担）、方块拼的（灶台、墙、门、桌凳）
- **真正的难点在材质和效果**：竹编纹理、麻袋布、灶火水汽、柚子绒毛，以及**割瓣时果皮外翻的变形**
- **七爪"开花"是最难也最出彩的一个动画**
- 传统器具大多没有齿轮、液压这类内部结构，**点开看结构意义不大，更适合点开看用法**（怎么握刀、刀路怎么走）
- 真正值得做剖面的只有两处：**灶**（灶膛、烟道、锅）和**焙炉**（火、隔层、果）

## 8. 下一步建议

1. 先做 **C 线橘红胎**——最简单：球体 + 绒毛材质，不做割瓣，能最快验证"分叉结构"跑不跑得通。
2. 再做 **A 线五爪**——只改一个常量，用来验证参数化是否真的可复用。
3. 最后做 **B 线压果片**——多出「压」和「切」两个动作，工具全在家常范围：木压果器压扁、竹筒定型，手工刀切片。视觉上「压 + 切」最有冲击力。

三条变体共用这一份文档 + 现有代码基础，不需要再放任何外部模型。
