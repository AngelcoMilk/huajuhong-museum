## 二、编号与标注规则

| 前缀 | 板块 | 编号范围 | 用途 |
|---|---|---|---|
| YQ- | 园区展示 | YQ-001～014 | 园区展板、图文页 |
| BO- | 博物馆展示 | BO-001～011、BO-A01～A04 | 馆内漫游入口、背景文章 |
| LS- | 历史文化 | LS-001～103 | 文章阅读、典故卡、诗歌页 |
| CP- | 产品中心 | CP-001～021 | 产品卡、产品详情 |
| QY- | 企业展示 | QY-001～035 | 地图点位、企业卡 |
| VR- | VR 全景 | VR-001～047 | 全景导览 |

每条记录统一带这些字段：

    id          素材编号（上表前缀）
    board       板块
    sub         子类（园区子栏目/历史子栏目/产品大类/馆内或车间等）
    type        条目类型（图文栏目/文章/产品/企业/VR场景）
    title       标题（原始名称）
    date        原始日期（企业页 2022-02-25；文章为发布日期）
    source_url  官网原文链接
    text        正文（原文照录，未改写）
    media       素材直链（images/videos/thumb/preview/slice_template 等）
    label       使用标注：usage 用途 / caution 口径提示 / copyright 版权

企业多出 town/address/tel/email/site/shops；产品多出 variants（包装名）；VR 多出 scene_id/gid/slices。

## 四、按板块怎么用

- **园区展示**：先读 01-园区展示.json 的 items（7 个子栏目全文）；页面上的 36 个园区 VR 场景在 vr_scenes（红峰农场、美华产业园、大岭村、农垦公园、新塘村五组），要全景就接 06-VR全景.json 的接口与场景。
- **博物馆展示**：02 里 8 个馆内场景（正门大堂、博物馆 1–6、橘香体验馆）+ 3 个配套车间；每个场景有 thumb/preview，可直接当封面。文章 4 篇用于背景与采风引用。
- **历史文化**：03 按 7 个子栏目分组，103 条全带全文；做文章列表、典故卡、诗歌页时按 sub 筛选，LS-ID 做锚点。
- **产品中心**：04 按 6 大类分组，21 件产品；variants 是盒装/竹篮装/桶装等包装名，详情共用一篇；shop_candidates 是导购候选，非官方绑定，下单以店铺实际为准。
- **企业展示**：05 是地图点位底表（QY-ID），有镇街/地址/电话/店铺/简介；4 家无地址、部分镇街待核，坐标需人工标点或调高德。
- **VR**：06 给接口（POST 地址、member_id、sign）和 47 场景；官网页面用 div 内嵌 kuleiman.com/147899，离线切片由 krpano 按 XML 解析，直链会 404。

## 五、缺口与注意

1. 图片/视频/店铺均为官网 CDN 或第三方直链，未下载，**可能失效**；做正式展陈前建议先跑一遍链接检查。
2. VR 是第三方酷雷曼项目 147899，切片 63,408 个未落地；自托管成本高，优先 iframe 嵌入并注明来源。
3. 企业坐标未生成：4 家无地址（鼎锋、桔利、同道堂、金睿），其余地址为注册/厂址文字；地图阶段需人工核对。
4. 产品没有价格、库存、SKU，店铺入口只是企业页外链；本包不提供下单数据。
5. 历史文化“药理作用”、产品文案含功效表述，属官网口径，不能当医学结论；对外展陈按 docs 里的《易错说法》《功效与用法（官网口径）》处理。
6. 版权：本包只整理官网公开图文与第三方 VR 链接；assets/refs-huajuhong 的 41 张调研照片版权属原媒体，未纳入本包。
