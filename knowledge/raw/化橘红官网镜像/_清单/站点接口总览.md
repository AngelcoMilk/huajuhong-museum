## 一、页面 URL 规则

| 类型 | URL 形式 | 说明 |
|---|---|---|
| 首页 | `/` | 静态渲染 |
| 栏目页 | `/h-col-{id}.html` | id = 栏目号 |
| 栏目页(参数式) | `/col.jsp?id={id}` | 与 h-col 等价 |
| 文章详情 | `/sys-nd/{id}.html` | 正文页，主内容 |
| 列表页 | `/sys-nr/{id}.html` | 静态渲染，含文章链接 |
| 产品详情 | `/sys-por/?_reqArgs={"args":{"id":N},"type":16}` | query 为 URL 编码 JSON |
| 产品分组 | `/sys-pr/?g={N}` | 12 个分组 |
| 产品静态 | `/sys-pd/{id}.html` | 模板演示页 |
| 站点地图 | `/sitemap.xml` | **806 条 URL 全量索引** |

### 请求注意
- `HEAD` 请求一律返回 **204**，必须用 `GET` 判断可达性
- 并发 ≥16 触发限流（返回 206 / 直接断 TLS），建议并发 ≤4 + 间隔 ≥0.15s
- 触发后冷却约 2 分钟恢复

## 四、VR 全景（第三方 · 酷雷曼）

**站内入口**：https://www.hzhjh.com.cn/h-col-165.html
（导航中 `display:none` 隐藏，实际内容是一个 iframe）

**iframe 地址**：https://www.kuleiman.com/147899

### 4.1 数据接口（可完整复现全站 VR 配置）

```http
POST https://live.kuleiman.com/home/Kuleimanxml/DataCace
Content-Type: application/x-www-form-urlencoded
Referer: https://www.kuleiman.com/147899

member_id=147899&sign_content=0
```

返回 JSON：
```json
{"status":0,"data":{"content":"<krpano XML 全文 287KB>","sign":"84f01a4fae6da7999b60b011df018ed1"}}
```

- `data.content` = 完整 krpano 场景配置（**明文**，47 个 scene，含全部图片路径、热点、背景音乐）
- `data.sign` = 签名，可回填 `sign_content` 复用
- 抓取命令：
```bash
curl -s -X POST "https://live.kuleiman.com/home/Kuleimanxml/DataCace" \
  -H "Referer: https://www.kuleiman.com/147899" \
  --data "member_id=147899&sign_content=0" -o vr_config.json
```

### 4.2 krpano 引擎与加密
- 场景 XML：`https://live.kuleiman.com/static/pano/xml/tourw.xml` → **KENCRURR 加密**，不可直接用
- 但上面的 `DataCace` 接口给的是**明文**，无需破解
- 引擎脚本：`//live.kuleiman.com/static/pano/js/panoszzz.js`、`open.js`

### 4.3 全景图资源
| 类型 | URL 模板 | 实测 |
|---|---|---|
| 场景缩略图 | `https://imj.kuleiman.com/132221/scene/{scene}/pano_thumb.jpg?{ts}` | **200 · image/jpeg** |
| 全景预览图 | `https://imj.kuleiman.com/132221/scene/{scene}/view/preview.jpg?{ts}` | **200 · image/jpeg** |
| 立方体切片 | `https://imj.kuleiman.com/132221/scene/{scene}/view/pano_%s/klm_%vklm%u.jpg?{ts}` | 404（见下） |
| 背景音乐 | `https://audio.kuleiman.com/member_132221/music/{hash}.mp3` | 需 Referer |

**下载必需**：`Referer: https://www.kuleiman.com/147899`
（不带 Referer → 403；带错 Referer → 404）

**切片说明**：47 场景共 **63,408 个切片文件**（CUBE 立方体 + 多分辨率金字塔，每场景 5 档 × 6 面 × N×N 瓦片）。
直接构造 URL 目前返回 404，实际加载由 krpano 引擎内部处理。需要离线全景时，建议：
1. 保存 `vr_config.json`（明文 XML）
2. 用 krpano 官方 viewer 加载该 XML，让它自己解析切片路径
3. 或浏览器打开 https://www.kuleiman.com/147899 ，DevTools → Network 过滤 `imj.kuleiman.com`，即可看到真实请求规律
