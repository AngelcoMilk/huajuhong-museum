## 使用规矩

1. **只读。** 本目录任何文件不改；核对只在原文上读，改写与提炼进 `wiki/`。
2. **引用格式**：文章标题 + 发布日期 + 本地路径，例如「《园区支持政策》（2022-03-16，`articles/2022/2022-03-16_0940_园区支持政策.md`）」。
3. **口径提醒**：官网文章多为宣传稿/转载稿。涉及功效、历史年代、绝对化数字时，先与 `wiki/质量标准.md`、`wiki/易错说法.md`、`wiki/产业数据.md` 交叉核对；功效只当「官网口径」记录，不作医学结论。
4. **版权**：图片、视频、VR 均未落地；对外发布前需核实版权与授权，内部研究与毕业设计使用。
5. **找原页面**：本文目录不含站点 HTML；需要看官网原版式时到 `~/Desktop/化橘红官网镜像`（`启动浏览.command` 或 `python3 -m http.server 8899`）。
