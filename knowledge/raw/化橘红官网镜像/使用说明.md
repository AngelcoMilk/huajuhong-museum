## 怎么打开（推荐用本地服务，别直接双击）

### 方式一：双击 `启动浏览.command`（推荐）
会自动起一个本地服务（端口占用就自动顺延）并打开浏览器，关掉终端窗口即停止。
用本地服务而不是 `file://`，是因为凡科的部分脚本在 `file://` 下会被浏览器安全策略拦截，
用 http 打开最接近官网真实表现。

### 方式二：命令行
```bash
cd ~/Desktop/化橘红官网镜像
python3 -m http.server 8899
```
浏览器访问 <http://127.0.0.1:8899/index.html>

> 直接双击 `index.html` 也能浏览、站内链接同样能跳，只是少数 JS 模块可能不工作。

### 方式三：Windows 用户

Windows 端**不需要装 Python 或任何环境**，双击即用：

| 文件 | 用途 |
|---|---|
| `index.html` | **直接双击就能看**（已实测可用） |
| `启动浏览-Windows.bat` | 一键打开首页（与双击 index.html 等价） |
| `启动本地服务-Windows(可选).bat` | 装了 Python 3 才用：起本地服务并打开；没装会自动退回打开 index.html |
| `Windows-使用说明.txt` | 纯文本版说明，可直接发给人看 |

已实测（Chrome / Edge，`file://` 方式）：站内链接可跳、导航下拉菜单可点、样式与图片正常。
从网盘/邮件收到的 `.bat` 可能被 Windows SmartScreen 拦截，点「更多信息 → 仍要运行」即可；
不放心就跳过它，直接双击 `index.html`。

## 本次链接修复做了什么

问题根源不是"页面没抓到"，而是**链接参数写法与本地文件命名不一致**：

| 问题 | 处理方式 | 修复数量 |
|---|---|---|
| 文章页侧栏写成 `sys-nr/?mid=12&g=25`，本地按 `?g=25` 存 | 去掉 `mid` 等噪声参数后重算本地文件名 | 2,111 处 |
| 产品入口 `sys-por/?_reqArgs={...},id:49,"_php":"..."}` | 解析 JSON、去掉 `_php`、只保留 id 再定位 | 同上 |
| 早期改写残留 `col__xxx.jsp`（文件已改名 .html） | 扩展名同步 | 234 处 |
| 分页控件的 `href="."`（靠 JS 翻页） | 指回当前页，点击不再报错 | 54 处 |
| "更多 / MORE"按钮 `sys-nr/?_reqArgs=...type:15` | 指向标题为「新闻中心」的列表页 | 176 处 |
| CDN 样式里的 `/image/...`（head 背景、图标、字体） | 补成原始 CDN 绝对地址 | 1,145 处 |

修复脚本：`~/Documents/逆向/hzhjh_crawl/fix_links_offline.py`
（默认预演不写入，加 `--apply` 才执行；可重复运行，幂等）

## 导航/下拉菜单点击修复（第二轮）

**现象**：鼠标悬停展开的下拉菜单（如「园区介绍 → VR展示/基础情况/…」）点了没反应。

**结论：不是没爬到页面**，这 7 个页面本地都在（`site/h-col-165.html` 等）。
真正原因是凡科的点击拦截函数 `JZ.setUrlArgToCookieAndJumpByWindowOpen()`：
它会**先请求服务器写 cookie 再跳转**，本地镜像没有这个接口（返回 501/404），
请求失败后跳转被吞掉 —— 而它已经调用过 `preventDefault()`，所以看起来"点了没反应"。

**处理**：往全站 1017 个 HTML 注入一段离线补丁（`<!--offline-nav-shim-->`），
把该函数替换为「直接本地跳转」，并置空无用的写 cookie 函数。补丁幂等，重复注入会跳过。

已实测通过的交互：
- 一级导航点击（园区介绍 → 栏目页）
- 悬停下拉菜单项（VR展示 / 基础情况 / 企业展示下 36 个企业…）
- 导航右侧 `»` 翻页箭头（窄屏时把隐藏菜单滚动进来）

**顺带解决缓存坑**：新增 `_serve.py`（`启动浏览.command` 已改用它），
响应头强制 `Cache-Control: no-store`，避免浏览器缓存旧页面让改动"看起来没生效"。
如果之前打开过旧页面，重启一次启动器即可；仍异常就 `Cmd+Shift+R` 硬刷新。

## 已知限制（如实说明）

1. **图片/视频未落地**（按你的要求）：联网时从原 CDN 加载，**断网会裂图**。
   全站 4,534 个图片地址约 1.48 GB，185 个视频共 15.45 GB，需要时可以用
   `mirror.py --with-media` 重新抓或让我补下载。
2. **VR 全景**是第三方酷雷曼平台的 iframe，不在本站内；47 个场景清单在 `_清单/`。
3. **交互功能**（留言板提交、站内搜索、分页的 AJAX 翻页）依赖服务端，离线不可用；
   页面本身可正常查看，页码链接会指到列表第一页。
4. **统计/埋点脚本**离线会报 404，不影响页面显示。
5. 部分老 IE 补丁文件（`PIE.min.htc` 等）原站本身已 404。
