# 技术选型：网页建模用什么

## 先分清三种“网页建模”

| 类型 | 建什么 | 代表 | 适合 |
|---|---|---|---|
| **A 3D 场景/设备** | 机器、产线、果实 | three.js / Babylon.js / model-viewer | 结构展示、动作、爆炸图 |
| **B 流程/工艺图** | 工序、设备-工序关系 | React Flow / X6 / bpmn-js | 可点可查的交互流程图 |
| **C 参数化结构** | 模具型腔、零件 | JSCAD / manifold | 改参数自动生成几何 |

> 大多数人说的“网页建模”是 B，但想要的画面是 A。**两者分开做。**

## 选型决策树

1. **有没有现成 glTF？**
   - 没有且不会建模 → 先做流程图 + 曲线，3D 延后
   - 没有但能建模 → Spline/Womp 出简易 glb，`model-viewer` 先跑通
   - 有 → 直接 `r3f`
2. **要不要“动”**（合模、气流、分度转）？
   - 不要 → `model-viewer` 够，代码 10 行
   - 要 → `r3f`（声明式）或 `Babylon`（内置动画/物理）
3. **是展示还是仿真？**
   - 展示 → three 系
   - 算产线节拍/能耗 → 用 ECharts 算，别上物理引擎

## 一种可行组合

```
Vite + React + TS
├── 工艺页     React Flow（13 道工序 + 设备卡片）
├── 设备 3D    model-viewer 起步 → r3f + drei
├── 展台       r3f + drei + Environment(HDRI)
└── 曲线沙盘   ECharts（五阶段可拖动 → 实时重算含水率）
```

三页各做一件事，别合并。

## 已知问题

| 问题 | 说明 |
|---|---|
| 手机面数 | 单场景三角面控制在 **< 15 万**，否则低端机掉帧 |
| 金属材质 | 金属度高的外壳在无环境贴图时显示为全黑（见 `HDRI与环境光.md`） |
| 光照 | 用 drei 的 `Environment` 预设，别自己打光 |
| CDN | 原型用 jsDelivr 可以；**正式版必须本地化依赖**，答辩断网即白屏 |
| 转换器 | gltfjsx 停更，glb 处理统一走 glTF-Transform CLI |
