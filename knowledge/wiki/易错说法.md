# 易错说法核查表

> 写展品文案、讲解词、论文之前，逐条对一遍。**左边这些说法在网上流传极广，但都是错的或不严谨。**

| 流传说法 | 核查结论 | 可用表述 |
|---|---|---|
| “化橘红就是橘子皮” | 错。是**化州柚幼果的外层果皮** | “柚类橘红，不是橘类橘红” |
| “李时珍《本草纲目》记载化橘红” | 《本草纲目》（1596）**没有“化橘红”专条**，这个药名是清代才定型的 | “清代赵学敏《本草纲目拾遗》明确记载” |
| “《神农本草经》有化橘红” | 原书只有“橘柚”，是柑橘类泛称 | 不作史料引用 |
| “种植历史 1600 年 / 2000 年” | 属地方文化叙事；文献可考的**药用记载在明清** | “地方口径称可追溯至晋代；文献记载见于明清” |
| “每个要压 99 下” | 营销话术，现代为机械压制 | 不提 |
| “柚皮苷高 4 倍” | 需指明对照对象与检测报告 | “橘红胎柚皮苷高于常规果皮（附检测）” |
| “七爪只是好看” | 七爪是**贡品制式**，且整体去瓤更均匀、陈化更稳定 | “七爪是等级与工艺的双重标识” |
| “所有橘红都能叫化橘红” | 仅化州产区 + 地理标志授权可用 | “需地标授权与专用标志” |
| “烘得越干越好” | 药典水分 ≤11%，过干易碎、损毛 | “按药典含水率控制” |
| “愈陈愈良，越久越好” | 传统经验，缺统一陈化度标准 | “陈化有传统认知，客观判定仍在研究中” |
| “化橘红能治咳嗽/消炎/抗癌” | 功效宣称，需药品资质 | 只引药典功能主治原文 |
| “化橘红是化州独有所以外地种不出来” | 外地能种，但**绒毛变稀、柚皮苷下降**，品质不达标 | “唯化州所产品质达标，外地引种品质下降” |
| “明清贡品是慈禧定的” | 明清两代列为贡品是方志口径；**具体到某个人属传说** | “明清时期列为宫廷贡品” |

## 还有三个容易搞混的工艺点

| 容易错 | 正确 |
|---|---|
| 以为“80–90℃”是烘干温度 | 那是**杀青**温度；烘干是 45–70℃ |
| 以为七爪和圆果是两套完全不同的设备 | **压形与压果是同一台压果机**，换模具和行程 |
| 以为先割瓣再杀青 | 药典是**先沸水略烫，再割瓣** |

---

## 引用时的规矩

1. 凡引药典，写明“《中国药典》2020 年版一部”。
2. 凡引方志，写明版本年份（乾隆十三年 / 光绪十四年）。
3. 凡引传说（罗辨、范祖禹、州官治咳、婢女复生、龙化橘树、鸟送橘种），**标注“相传”“传说”**，不要写成史实。
4. 凡引网络文章，先回到原始出处；找不到原始出处的，不进正式文案。
