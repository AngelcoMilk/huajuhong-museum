## 一、化橘红专用的 5 类

### 1. 七爪等分切瓣机（结构最复杂）

商品机两台，外形与操作都有出处：

| 厂家 / 型号 | 外形 | 功率·产能 | 价格 | 操作 |
|---|---|---|---|---|
| 广州达桥 化橘红切瓣机（ZL2013 1 0252643.0） | **600×600×1100 mm，60 kg** | 0.1 kW + 耗气 0.2 m³/min；**20 个/分**（同页概述另写 25 个/分） | 未见公开价 | **1 人**定向放果入刀笼，"仿形压果手"自动压切；3–8 瓣；果径·果高 40–200 mm |
| 沧州万顷 **WQ-HJH200**（万顷隆） | 未见公开尺寸 | 2.2 kW / 380 V，净重 600 kg，**链轨式** | **68000 元/台**（2024-09-16 B2B 参考价，**型号二次检索零命中，标未公开可核**） | 链轨输送；标题口径"切片均匀**不切到底**" |

> 口径注意：达桥参数区 20 个/分、概述写 25 个/分；万顷标称 **200–300 个/分（0.2–0.3 s/个）**，与达桥差一个数量级，按**标称值存疑**处理。建模节拍取 **2.4–3 s/个**（达桥口径）。

专利结构（`CN114654521A`，申请号 202210330144.8，2022-03-31 申请、06-24 公开，李银朵；**无授权文本**，CN114654521B 为 404）：

- 机架 + **半环状空心壳（开口向上的 U 形）**，绕一根水平钢管翻转；中心**插杆**固定果
- 壳内径向一排**圆筒 + 活塞板 + 压簧 + U 形板 + 锥形轮子**；轮子接触果面 → 果径大则外移 → 液压升高 → **切深一致**
- 钢管外端接**液压缸**，内端固定**齿圈**；小齿轮（带单向离合器）沿齿圈滚动，**传动比锁 1/7 圈**；改传动比可做五爪，"理论上任意瓣数"
- 刀片下端开**两个反括弧弧形槽**，内置弧形切刀，下行时**把果皮向外翻**，为去瓤标厚度
- 无传感器，纯机械液压自适应；**刀片尺寸/行程/液压压力全文无 mm、MPa**
- ⚠️ **是单刀，不是七把刀**：滑筒 17 下端固定**1 把竖直刀片 18**，靠"果转动刚好转过 1/7 周"分度，**转七次扎七次**才成七爪；切深由机械限位（环形凸起 23）保证
- 对照另一条路线（别混画）：达桥式 `CN103330263A`（ZL201310252643.0）"刀座内部安装 **2～12 个切瓣刀片**，切瓣刀片组成倒置的圆锥结构"，气动**一次压切**成型 3–8 瓣

变体 `CN114670265A`（同发明人 + 漯河市利道液压）：滑筒内改**往复丝杠 + 螺母**，刀片上下**连续刺扎**；副刀经矩形块—螺旋槽—小轴出刀，"副刀宽度小于刀片厚度"。

### 2. 旋挖去囊机（去瓤机）

`CN112106998A`（申请号 202011000128.X）+ 实用新型同族 `CN213819751U`（202022100572.0）；申请人为**广东石油化工学院 + 茂名本正化橘红研究院**（调研报告另记化州市正源堂参与，以公告文本为准）。

- 结构：机架 + 丝杆/电机 → 安装台；**旋转刀杆** + 锥形刀刺刀头；安装套 + **2 把对称弹性刀片**；顶杆插刀杆空心孔
- 传动：电机—带轮—皮带转刀杆；另一电机—丝杆—驱动板压刀片端距 → 弹性刀片**外弯成弧形**
- 适用边界（原文）：**果龄 >55 天、果径 >90 mm 的原果一般需要去囊**；41–55 天的胎果不需去囊
- ⚠️ **仍未商品化**：市场买不到，只有样机与专利；现场也查不到实拍
- 整机尺寸、转速、刀片尺寸、单果耗时：专利与商品页**均无** → 建模全示意值

### 3. 压果机 / 圆柱成型机

`CN217040801U`（申请号 202220081126.6，2022-07-26 授权，化州橘红生物科技）：

- 机架 = 底架 + 工作台 + 支撑架；**防护栅**围住压力装置并留**置料口**
- 两套压力机构，动力方向**相互垂直**：垂直缸 + 推板 + **上压模**；两台水平缸 + **侧推模** + **后模**
- 侧推模与后模各开半圆槽，合成**圆柱压料腔**；槽内壁与上压模底面**全为光滑面**（护表皮绒毛）
- 液压油箱 + 油泵；**红外对射**装在置料口两侧 + 智能控制系统 + 双按钮
- 动作顺序（原文）：**垂直缸先把圆果压成扁状 → 水平缸把压扁的果推入后模压成圆柱**
- 压力/行程/节拍：专利无

第二件 `CN211390274U`（**= 申请号 201922355516.9**，化州市正源堂，李海波）：上冲模 + 两侧侧冲模；驱动斜面上端再加**反向斜面**形成**拐点 a**，驱动轮过拐点时侧冲模**横向振动** → 帮助脱模（烫软的果会粘模）。

制型参数（`CN110812403A`）：套具直径 **60–74 mm**（优选 68/70/72）；第一步柱径 **≈80 mm**、第二步 **75 mm**；**静置 5–30 min**；长径比 **1:0.5–1:0.7**；鲜果直径 **75–130 mm**。

商品机（只到定性）：液压式、非标定制、无统一型号；**3.8 秒/个、1 人操作、单台日出一万个**；红外安全 + 压完自动退料；"几万元一台"。吨位与外形尺寸无公开出处。

**现场在用构型（2026-10-26 实拍，展厅主图按此）**：蓝色大圆盘回转料斗 + **米白塑料套筒（带套防裂）** + **3–4 根竖直气缸吊在铝型材横梁** + **黑色聚氨酯圆台压头** + 一对**铜色夹模座**，敞开式无外壳，节拍 3.8 s/个。另一种在售机为**立式上压多腔模**（合盈牌：蓝缸带 4 导柱 + 台面模具板 + 下部液压站 + 触摸屏控制箱）。专利那套"垂直缸 + 双水平缸"现场未见使用。

## 三、温控设备四层差异

| 层 | 差异 | 影响 |
|---|---|---|
| 热源 | 柴火 / 煤 / 电热 / 空气能热泵 / 微波 / 真空冷冻 | 毛色、香气、成分留存、成本 |
| 控温 | 不可控 → 定时 → 分段程序 → 智能联网曲线 | 能不能做"五阶段"，决定等级 |
| 气流 | 自然对流 / 平流 / 穿流 | 干燥均匀性、外干内湿 |
| 除湿 | 直排 / 热回收 / 换气+除湿 | 能耗、能否压到 RH 10% |

**柴火 vs 电烘（经验口径，非标准）**

| | 时间 | 一斤鲜果得干重 | 外观/香气 | 成本 |
|---|---|---|---|---|
| 柴火 | 5–7 天 | ≈110 g | 色偏深、**药香突出**、敲声低沉 | 低 |
| 电烘 | ≈8 天恒温 | ≈90 g | 色自然、**果香明显**、敲声清脆 | 高 |
| 热泵 | 4 天（智能型） | 介于两者 | 护毛好、色匀 | 中 |

> 风味不同 ≠ 低档。非遗叙事里柴火反而是卖点。

## 四、外形与现场设定（实拍）

广东农垦广垦化橘红趁鲜切制车间（化州）：

- **配色**：不锈钢银白机身 + **蓝色方管机架 / 蓝底白字标牌**；白色彩钢夹芯墙、**浅绿环氧地坪**；点缀黄黑警示条
- **管线**：白色 PVC 喷淋管 + 红白球阀
- **控制柜两型**：① 米白立式 **1.6–1.8 m**，柜面 3×4 指示灯阵列 + 按钮，带轮；② 黄黑斜纹立式 **≈1.2×1.8 m**，自上而下红色急停 → 一排绿红指示灯 → 3–4 旋钮 → 数排按钮，柜门贴红色厂牌
- **人机比**：前处理连续线 **2 人**同侧站立（深蓝工装 + 深蓝棒球帽）；杀青 **2 人**持长柄不锈钢漏勺（勺头 Ø≈30 cm）捞果入橙/黄周转筐；割瓣仍是 **8–10 人**围桌手工；中试烘干 **2 人**（白大褂 + 蓝丁腈手套）抽盘
- **产线布局**（招标公告口径）：前处理线 1 组 + **热泵烘干房 5 套** + 压条果线 1 组 + 切制线 1 组 + 干果包装线 1 组 + 恒温仓库 1 间；限价 400 万、工期 90 天
- **现场尺度**：前处理线长约 **8–10 m**；杀青烫锅 Ø≈1 m + 白护罩输送段 ≈2.5 m；中试干燥柜宽 ≈1.2 m、6–8 层托盘

### 第二轮补充（视频与照片，2026-10-26）

**压果机（现场在用构型，两种）**
- 转盘多工位气动：蓝色大圆盘回转料斗 + **米白塑料套筒（带套防裂）** + **3–4 根竖直气缸吊在铝型材横梁** + **黑色聚氨酯圆台压头** + 一对**铜色夹模座**；敞开式、无外壳、无防护罩，水泥地面，节拍 **3.8 s/个**、单台日产 1 万
- 立式上压（合盈牌）：白色方管机架 + 4 脚轮；**蓝色立式气缸带 4 根金黄导柱**；台面**多腔模具板**；下部液压站 + 压力表；右后挂控制箱（触摸屏 + 红色急停）
- 成品：扁圆饼 **φ30–40 mm × 厚 15–20 mm，长径比 ≈2:1**，绒毛细密

**旋挖去囊机（样机实拍）**
- 现场是**铝型材台式机**：双立柱 + 步进电机 + 丝杆 + 双直线导轨，中空圆筒刀下垂，果坐在**白色 3D 打印环形/4 爪仿形果托**上；右侧一格标注"底部刀片运动"——**白色辐条转盘 + 黑色弧形刀片**在挖空果壳内环切；台面有白色亚克力罩板、红色急停、端子排
- 论文图 1 是另一套**四龙门工位流水线**（激光位置传感器 → 摄像平台 → 单瓣切割 → 旋转去瓤 → 七瓣切割）
- 真实产能 **800 个/小时**、果皮损失率 **≤3%**

**智能烘房（门与内部）**
- 门 = **左开单扇保温门 + 3–4 个重型不锈钢合页 + 不锈钢把手 + 铝门槛踏板**（不是双开门）
- 正面上部偏右挂**灰色小电控箱**；右侧地面**双风机空气能热泵主机**，白色保温管接入
