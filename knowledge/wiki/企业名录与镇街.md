## 三、地图点位口径

- 点位 = **镇街中心**（OSM / Nominatim）+ 同镇内按企业编号确定性错开，**不是门牌坐标**
- 坐标系统：底图（高德）与市界（阿里云 DataV 440982）是 **GCJ-02**，OSM 点位按 WGS-84 转入 GCJ-02
- 尺度行为：县域尺度只画**镇街合并块**（块内是家数）；放大到 10.6 级以上才拆成企业单点
- 防遮挡：任意两块中心距离小于 56px 就强制合并，保证任何缩放级别都不重叠
- 图上只做分布索引，**不作导航**；点位精度以镇街为限

## 四、站内数据与字段

- 数据文件：site/src/data/enterprises.json（34 条），生成脚本 site/scripts/sync-enterprises.mjs
- 字段：id / name / town / address / tel / email / site / shops / text / date / sourceUrl / images / videos / articleCount
- 文案：官网原文照录，**只做排版整理**（断段、去重复标点、合并中英文空隙、小标题转楷体小节、（1）… 条目单独成行），不改字词
- 媒体：官网图 **691 张**（每家在页面上取前 8 张，其余给外链）；视频 **2 条**（QY-001、QY-016），页内播放
- 覆盖：官网标了地址的 **30 家**；列了网店的 **11 家**；地址缺失 **4 家**（QY-016 化州鼎锋、QY-021 桔利、QY-023 同道堂、QY-029 金睿）

## 五、已知缺口

1. 镇街只是**归属**，没有门牌级坐标；「同镇错开」是排布，不是真实位置
2. 「橘之饮公司经营主体」「复兴隆化橘红经营主体」是官网栏目里的主体名，不是工商全称
3. 官网企业页抓取于 2026-10-20、页面日期 2022-02-25，**企业现状可能已变**（经营状态、电话、网店链接）
4. 35 个企业页里 1 家移除，完整名单与口径见 [docs/16](../../docs/16-企业展示素材.md)
