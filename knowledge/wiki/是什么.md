# 化橘红是什么

## 一句话

**化州特有的一种长绒毛柚子的幼果外层果皮**，不是橘子，也不是橘子皮。

## 法定定义（可直接引用）

> 本品为芸香科植物**化州柚 *Citrus grandis* 'Tomentosa'** 或**柚 *Citrus grandis* (L.) Osbeck** 的**未成熟或近成熟的干燥外层果皮**。前者习称“**毛橘红**”，后者习称“**光七爪**”“**光五爪**”。夏季果实未成熟时采收，置沸水中略烫后，将果皮割成 5 或 7 瓣，除去果瓤和部分中果皮，压制成形，干燥。
> ——《中国药典》2020 年版一部，第 74 页

## 名称对照

| 名称 | 指什么 |
|---|---|
| 化橘红 / 化州橘红 | 正名，地理标志产品名 |
| 毛橘红 | 化州柚（有绒毛）加工的，品质优 |
| 光橘红 / 光七爪 / 光五爪 | 普通柚（无毛）加工的，价低 |
| 橘红 | 更宽泛，历史上还包含“橘类橘红”（柑橘成熟果皮） |
| 七爪 / 五爪 | 按割瓣数分的规格，七爪为贡品制式 |
| 橘红胎 / 胎果 | 生理落果或疏下的幼果**整果**，柚皮苷最高 |
| 橘红珠 | 中等幼果整果 |
| 圆果 / 压果 | 整果压成圆柱形后再切片的形态 |

## 最容易混的一点

- **橘类橘红**：柑橘（*Citrus reticulata*）成熟果皮，10 月后采，片薄色红，如川橘红
- **柚类橘红 / 化橘红**：化州柚幼果外皮，5–6 月采，密布绒毛，七角星形

药典自 1977 年版起把“化橘红”独立成条，**只要柚类来源**。

## 怎么一眼认出真货

| 特征 | 真（毛橘红） | 假 / 劣 |
|---|---|---|
| 绒毛 | 密布、白、长 | 无毛、毛稀而短 |
| 形状 | 对折七角或展平五角星，直径 15–28 cm | 不规则碎片 |
| 色 | 外黄绿、内黄白 | 焦黑、染色 |
| 气 | 芳香，有陈皮样香 | 霉味、无香 |
| 味 | 苦、微辛 | 淡或麻舌 |

## 为什么只有化州能种出“毛”

1. **礞石土壤**：化州城内宝山及州署一带富含礞石，富硒、富锗，与化橘红形成共生关系
2. 罗江、鉴江流域小气候，湿热同期
3. 本地无性系品种群（正毛、黄龙等）
4. 反证：广西陆川、吴川引种能结果，但绒毛变稀、柚皮苷下降——旧志也说“惟署内城内者宜用”

## 品种（五大栽培品种）

| 品种 | 特征 | 备注 |
|---|---|---|
| **正毛** | 果不正梨形，茸毛多、长、密；烘干果皮黄、毛白 | 种植面积最大；资料中评价“厚叶正毛”品系最优 |
| **黄龙** | 树形直立簇立，果扁圆，毛多长密；烘干果皮金黄、毛白 | 颜色最靓 |
| **密叶** | 分枝多，果开肩梨形，毛介于黄龙与西洋之间 | 最丰产稳产 |
| **西洋** | 树开阔，果近圆，毛短；烘干色偏黑、密度大 | 最宜切片；树龄最长 |
| **副毛** | 果梨形，毛短而稀；烘干色黑 | 坐果力强，可作授粉树 |

另有株系：金钱脐、凤尾、红肉、陆福、大茶岭、无叶翼。
