# 质量标准

## 药典全项指标（可直接引用）

| 项目 | 要求 |
|---|---|
| 来源 | 化州柚 *C. grandis* 'Tomentosa' 或柚 *C. grandis* (L.) Osbeck 的未成熟/近成熟**干燥外层果皮** |
| 采收 | 夏季果实未成熟时 |
| 性状 | 对折七角或展平五角星，单片柳叶形；直径 **15–28 cm**，厚 **0.2–0.5 cm**；外黄绿、密布茸毛、有凹陷小油室；内黄白/淡黄棕、有脉络纹；气芳香，味苦微辛 |
| 水分 | **≤ 11.0%** |
| 总灰分 | **≤ 5.0%** |
| **含量测定** | 按干燥品计，含**柚皮苷（C₂₇H₃₂O₁₄）不得少于 3.5%** |
| 鉴别 | TLC（乙酸乙酯-丙酮-冰醋酸-水 8:4:0.3:1，5% 三氯化铝，365 nm） |
| 炮制 | 除去杂质，洗净，闷润，切丝或块，晒干 |
| 性味归经 | 辛、苦，温。归肺、脾经 |
| 功能主治 | **理气宽中，燥湿化痰。用于咳嗽痰多，食积伤酒，呕恶痞闷** |
| 用法用量 | **3–6 g** |
| 贮藏 | 阴凉干燥处，防蛀 |

> **版本注**：1990 年版功能主治为「散寒，燥湿，利气，消痰。用于风寒咳嗽，喉痒痰多，食积伤酒，呕恶痞闷」；2020 年版为「理气宽中，燥湿化痰…」。引用时须注明版本，本页指标按 2020 年版。

## 含量限度的演变（说明“越来越严”）

| 版本 | 限度 |
|---|---|
| 1985–2005 | 柚皮苷 ≥ **1.5%** |
| 2020 | 柚皮苷 ≥ **3.5%** |

> 数字翻倍，意味着过去合格的货现在不合格——这是产业升级的硬约束。

## 标准体系（不止药典）

| 层级 | 举例 |
|---|---|
| 国家药典 | 《中国药典》2020 版一部“化橘红” |
| 地理标志产品 | 2006 年第 219 号公告及其产品标准 |
| 地方标准 | **DB4409/T 32-2023《化橘红烘干加工技术规程》**（茂名市地方标准，把杀青+热风干燥参数表格化） |
| 团体标准 | T/GDATCM 0004—2026《化橘红（柚）药材质量控制技术规范》、T/UNP 137—2026《富硒产品 化橘红》、T/GDP 049—2025《病虫草害减药控害技术规程》、T/MMZYY 01—2023《高凉菜 化州橘红蒸老鸭汤》 等 |
| 企业标准 | Q/HZHJH 系列 |

## 化学成分

| 类别 | 主要成分 |
|---|---|
| 黄酮类（主要） | **柚皮苷 naringin**、**野漆树苷 rhoifolin**、新橙皮苷、枸橘苷 |
| 挥发油 | 柠檬烯等 |
| 其他 | 多糖、香豆素类 |

**作用机制（学术口径）**：柚皮苷与野漆树苷被用作质量控制指标；药理研究集中在抗炎、抗氧化、抑制 NLRP3 炎症小体、抗铁死亡等通路。

# 合规红线（写文案必看）

## 可以说

- 药典原文：**“理气宽中，燥湿化痰。用于咳嗽痰多，食积伤酒，呕恶痞闷。”**
- 历史文献：清代《本草纲目拾遗》“治痰症如神”；光绪《化州志》“治痰如神，每片真者值一金”——**标明出处、注明是历史记载**
- 现代研究：“研究表明……（附文献）”，只描述研究方向，不承诺疗效

## 不能说 / 要避开

| 不能说 | 原因 |
|---|---|
| “治咳嗽 / 治哮喘 / 消炎 / 抗癌” | 功效宣称，需药品资质 |
| “提高免疫力 / 排毒 / 戒烟” | 保健功能宣称 |
| “柚皮苷高 4 倍” | 无对照、无检测报告的绝对化比较 |
| “愈陈愈良，永不过期” | 传统经验，缺乏统一陈化度标准 |
| “李时珍《本草纲目》记载化橘红” | 见 `wiki/易错说法.md` |
| “正宗”“第一”“最” | 广告法绝对化用语 |
