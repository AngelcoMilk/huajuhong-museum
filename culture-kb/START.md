# 文化知识库 · 入口

> 化州橘红的文化内容库：历史、典故、诗文、品种、工艺、产品、企业园区、产业数据、馆藏展陈。
> **代码与工程内容不在这里**（框架、目录、命令、部署、接口、构建坑 → 去 `.kb/`）。
> 只读这一页就能定位全部内容；要细节再点进去。

## 三条规矩

1. **只读命中的那一页**，不要整目录读 `sources/`（原文摘录按页切好，通读等于回到通读原文）
2. **命中不了就说"库里没有"**，不用常识补
3. **每条陈述后面都要有〔出处〕**；写不出出处的句子不许进库

## 出处标签（四种）

| 标签形态 | 用于 | 例 |
|---|---|---|
| 〔网站名 · 《文章名》〕 | 官网、新闻媒体、政府网站 | 〔化橘红官网 · 《罗辨仙翁植橘》〕 |
| 〔《书名》〕 | 古籍、药典、方志 | 〔《本草纲目拾遗》〕〔《化州志》（光绪十四年）〕 |
| 〔知识库 · 详细调研 §X〕 | 内部调研报告（唯一内部底本） | 〔知识库 · 详细调研 §6.4〕 |
| 〔专利 CN…〕〔馆藏工艺档案〕 | 专利、馆藏与现场记录 | 〔专利 CN202210330144〕 |

标签全角〔〕、分隔用 ` · `。**同一句只标一个主出处**；有并列证据时另起一句标。

## 页面配对

每个主题两个文件，同名、一一对应：

```
wiki/<主题>.md      正文（句级出处，1–3 千字）
sources/<主题>.md   该页实际引用的原文段落（每段前标同一条〔出处〕+ 原位置）
raw/               随库自带的原文底本；sources 里的「原位置」都指向这里，整库可独立使用
```

## 文件名约定

主题名前置分类字母的类名，用 `-` 连接：`本体-法定定义与名称`、`源流-时间轴`、`典故-罗辨植橘`、`工艺-古法工序`、`产品-分类与形态谱系`、`标准-药典指标`、`企业-名录与镇街`、`数据-面积产量产值`、`展陈-VR场景清单`、`非遗-传承谱系`。
同一类下按主题排序，不建子目录。

## 给讲解员（pi）的接口约定

讲解员只读 `START.md` 与 `wiki/*.md`；页首 frontmatter 的 `sources` 是本页可引用标签的合集，正文里每个〔标签〕可直接作为 `citation.origin` 返回，`citation.source` 固定写"知识库"。
讲解员不得自行拼造标签；页里没有的出处，就回答"知识库里没有这一条"。

## 找不到怎么办

先按 [index.md](index.md) 的 12 类目录找；12 类都翻过还没有，就回答"知识库里没有这一条"，不要用常识补。

## 维护约定

新增或改动一页，必须同步做三件事：补齐同名 `sources` 页、在 [index.md](index.md) 对应类目里加/改一行、在 [log.md](log.md) 追加一条记录。
