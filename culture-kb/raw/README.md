# raw —— 随库自带的原文底本

这个目录让知识库做到自包含：sources/ 里每条「原位置」链接都指向这里，不依赖任何外部项目目录。整库拷到别处、发给别人，链接照样能点开。

## 结构与来源

目录层级沿用原项目路径，便于对照：

| 目录 | 对应原位置 | 内容 |
|---|---|---|
| raw/knowledge/raw/ | 项目 knowledge/raw/ | 化橘红完整调研报告（2026-10-19）；官网镜像 articles/2022/ 栏目页 174 篇 |
| raw/knowledge/wiki/ | 项目 knowledge/wiki/ | 历史时间轴旧整理页（非遗谱系转引底本） |
| raw/docs/ | 项目 docs/ | 设计中作为出处被引用的部分：01、06、18、19、23、25，以及 20-历史文化/ 与素材汇编 |

复制时间：2026-10-29；来源项目：本仓库。

## 收录口径

- 只收被引用到的：sources/ 与 wiki/ 里出现过的原文，共约 280 个文件；官网镜像不是全量 479 篇，而是被引用的那一批，加上整份 2022 栏目目录。
- 原文逐字保留，未做改写、删节或格式转换。
- 若以后要扩到官网全量镜像，把其余年份目录补进 raw/knowledge/raw/化橘红官网镜像/articles/ 即可，wiki 与 sources 不需要改。

## 注意

- 这些是副本，原始底本仍在项目里；以项目内的为准，这里用于随库分发与离线查看。
- raw/ 内的文件可能保留各自原有的相对链接，个别指向未收录的文件，属正常。
