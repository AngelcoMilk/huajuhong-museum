## 摘要：10 条核心结论

1. 化橘红不是"橘子"，而是**化州特有的一种长绒毛的柚子（化州柚）的幼果外层果皮**，法定基原见《中国药典》2020 年版一部第 74 页。
2. 药典只承认两个来源：**化州柚 Citrus grandis 'Tomentosa'（毛橘红）** 与 **柚 C. grandis (L.) Osbeck（光七爪/光五爪）**；前者价高，区别就在"毛"。
3. 道地性成因的核心解释是**化州礞石土壤（富硒、富锗）+ 罗江/鉴江流域小气候 + 本地无性系品种群**，外地产区引种后绒毛变稀、柚皮苷下降。
4. 药典法定工艺只有一句：**沸水略烫 → 割 5 或 7 瓣 → 去瓤与部分中果皮 → 压制成形 → 干燥**；1963 年版还记载了"回润—木板压平—复焙"的古法细节。
5. 历史可信链条是：**明代方志与贡品记载 → 清代《本草纲目拾遗》（1751）与《化州志》（乾隆十三年、光绪十四年 1888"每片真者值一金"）→ 1963 年药典收载 → 1977 年版起独立为"化橘红"**。网传"李时珍《本草纲目》记载化橘红"宜作文化叙事，不宜作史料。
6. 现代制度节点：**2006 年国家地理标志产品保护（质检总局 2006 年第 219 号公告）→ 2009"中国化橘红之乡" → 2012 省级非遗 → 2021 国家地理标志保护示范区 → 2024 药食同源目录 + 《茂名市化橘红保护发展条例》施行 → 2026 第八批中国重要农业文化遗产**。
7. 产业规模：种植面积 **3 万余亩（约 2005）→ 13.26 万亩（2024）→ 14.3 万亩（2026）**；全产业链产值 **35 亿（2020）→ 102 亿（2023）→ 115 亿（2024）→ 126 亿（2025）**；带动 35 万人。
8. **真正独有的机器只有五类**：七爪等分切瓣机、旋挖去囊机、压果（圆柱成型）机、化橘红定制智能烘房、压果专用切片机。其余为通用柑橘/果蔬设备。
9. 装备现状：切瓣机（约 7.8 万元/台）、自动压果机（数万元/台）、热泵烘房（3.5–7 万元/套）已商品化；**去瓤自动化率最低，是行业最后一块拼图**（AI 视觉 + 变径刀具已有样机与专利）。
10. 出成率是价格逻辑的根：**100 斤鲜果 ≈ 20 斤干果；只取皮做七爪，100 斤鲜果仅得约 4 斤干皮**（出皮率 4%）。

## 1. 定义与名称体系

### 1.1 法定定义〔典〕

> **化橘红 Huajuhong，CITRI GRANDIS EXOCARPIUM**
> 本品为芸香科植物**化州柚 *Citrus grandis* 'Tomentosa'** 或**柚 *Citrus grandis* (L.) Osbeck** 的**未成熟或近成熟的干燥外层果皮**。前者习称"**毛橘红**"，后者习称"**光七爪**""**光五爪**"。夏季果实未成熟时采收，置沸水中略烫后，将果皮割成 5 或 7 瓣，除去果瓤和部分中果皮，压制成形，干燥。
> ——《中国药典》2020 年版一部，药材和饮片，第 74 页

### 1.2 名称对照表

| 名称 | 实际所指 | 备注 |
|---|---|---|
| 化橘红 / 化州橘红 | 正名、地理标志产品名 | 官方宣传常用"化州化橘红" |
| 毛橘红 | 化州柚（有绒毛）加工品 | 药典两类中品质优者 |
| 光橘红 / 光七爪 / 光五爪 | 普通柚（无毛）加工品 | 价低，常被冒充 |
| 橘红 | 更宽泛的历史称谓 | 历史上包含"橘类橘红"（柑橘成熟果皮） |
| 七爪 / 五爪 | 按割瓣数划分的传统规格 | 七爪为贡品制式；改传动比可做五爪 |
| 黄七爪 / 绿七爪 / 大五爪 | 1963 年版药典记载的商品规格 | 见于老药典性状描述 |
| 橘红胎 / 橘红胎果 | 生理落果或疏下的幼果整果 | 柚皮苷含量最高，走高端 |
| 圆果 / 压果 | 整果压成圆柱体后再切片 | 化橘红独有工序产物 |
| 光青 / 光黄 | 表皮光滑无毛的品类 | 一般不用于药用 |
| 副毛 | 绒毛短而稀的品种 | 药效与价均低于正毛 |

### 1.3 关键区分（最易混淆）

- **"橘类橘红"**（*Citrus reticulata* 成熟果皮，如川橘红、浙江橘红）：10 月以后采成熟果，取外层果皮晒干或阴干；片薄、色红、油润。
- **"柚类橘红 / 化橘红"**（*Citrus grandis* 幼果外皮）：夏季采未成熟果，烫、割、去瓤、压形、干燥；呈七角/五角星状。
- 药典自 **1977 年版**起把"化橘红"独立成条，只保留柚类来源；1963 年版仍三者并列。

## 2. 植物学特征与道地性成因

### 2.1 植物学〔学〕

- 柚的栽培变种，乔木；学名 *Citrus maxima* (Burm.) Merr. cv. Tomentosa（三名法 *Citrus maxima* var. *Tomentosa*）。
- **嫩枝、叶背、花梗、花萼、子房及果实均被绒毛**——这是全株识别特征，也是药材真伪鉴别的第一依据。
- 与柚同属乔木，但果实小、皮厚、味苦辛。

### 2.2 药材性状〔典〕

| 项目 | 毛橘红（化州柚） | 光橘红（柚） |
|---|---|---|
| 形态 | 对折的七角或展平五角星状，单片柳叶形 | 五角形为主 |
| 展平直径 | 15–28 cm | 相近 |
| 厚度 | 0.2–0.5 cm | 相近 |
| 外表面 | 黄绿色，**密布茸毛**，有皱纹及小油室 | 黄绿色至黄棕色，**无毛** |
| 内表面 | 黄白色或淡黄棕，有脉络纹 | 同 |
| 断面 | 不整齐，外缘有 1 列不整齐下凹油室 | 同 |
| 气味 | **气芳香，味苦、微辛** | 气微香 |

### 2.3 道地性成因（四条）

1. **礞石土壤**：化州土壤蕴藏独特礞石矿脉，富含硒、锗等微量元素，与化橘红形成共生关系，是果实密生绒毛的物质基础〔政〕。
2. **小气候**：罗江、鉴江流域冲积丘陵，南亚热带季风气候，湿热同期、干湿分明。
3. **种源**：长期无性繁殖形成的本地品种群（正毛、黄龙、密叶、西洋、副毛及多个株系）。
4. **实践反证**：广西陆川、吴川等地引种后可结果，但绒毛变稀、柚皮苷下降；市场长期存在"广西橘红冒充化橘红"，也是化州持续打假、地方立法的直接动因。

## 3. 发展历史

### 3.1 起源：文献与传说分层

| 时段 | 证据性质 | 内容 |
|---|---|---|
| 东晋 | 〔传〕 | 潘茂名（"潘仙"）在高凉一带行医，以橘红治咳，被称"番仙" |
| 南北朝 | 本草渊源（泛指） | "橘柚"类药物范畴，非化州特产 |
| 唐代 | 〔传〕 | 罗辨仙翁行至罗江畔，饮石坑水而愈喘咳，遂植橘成林（"罗辨植橘"） |
| 北宋 | 〔传〕 | 史学家范祖禹贬化州，饮南山寺井水（井边有橘红树）而咳愈，题"橘红气，南山养性" |
| 南宋 | 〔企〕/地方口径 | 化州已开始成规模种植（化橘红官网表述） |
| 明代 | 可信 | 化橘红随"广药"北传；明清列为**宫廷贡品**；方志开始记述其特殊性 |
| 清代 | **确证文献** | 见下节引文 |

### 3.2 清代确证文献

- 赵学敏《本草纲目拾遗》（1751）："**化州橘红，治痰症如神，消油腻谷食积，醒酒宽中……**"
- 乾隆十三年《化州志》："化州橘红，有红白瓤之分。"
- **光绪十四年（1888）彭以孙《化州志》**："**化州橘红，治痰如神，每片真者值一金。**"——"一片值一金"即出此。

### 3.3 史观纠偏（重要）

| 流行说法 | 核查结论 |
|---|---|
| "李时珍《本草纲目》记载化橘红……其功效愈陈愈良" | 《本草纲目》（1596）无"化橘红"专条，"化橘红"作为独立药名清代才定型。该引文应视为**文化叙事**，不宜作史料引用 |
| "《神农本草经》记载化橘红" | 原书只有"橘柚"，为柑橘类泛称，不等于化橘红 |
| "种植历史 1600 余年" | 〔政〕人民网与政府口径表述为"可追溯至晋代，距今 1600 余年"，属**地方文化叙事口径**；有文献支撑的药用记载集中在明清 |
| "每个压 99 下" | 营销话术；现代为机械压制（专利明确针对人工敲打低效与伤手问题） |

## 5. 品种与种植

### 5.1 五大栽培品种〔企〕

| 品种 | 树形/叶 | 果与毛 | 烘干后 | 评价 |
|---|---|---|---|---|
| **黄龙** | 树形最直立簇立，冠幅小，分枝少；叶密而细长、厚 | 果不正扁圆，茸毛**多、长、密**，印圈下凹 | **果皮金黄、毛白**，色泽最佳 | 顶端优势最强；带独特椰奶香 |
| **正毛** | 枝梢直立，叶近棱形 | 果不正梨形，毛多长密 | 皮黄、毛白 | **种植面积最大**；"厚叶正毛"品系最优（平定镇六赠村） |
| **密叶** | 分枝力最强；叶椭圆、平展、厚 | 果开肩梨形，柱痕下凹 | 毛与色介于黄龙、正毛、西洋之间 | **丰产稳产**（平定镇积田村） |
| **西洋** | 树形开阔飘逸，冠幅大；叶不对称、皱 | 果近圆，毛**较短** | 果色较黑、果心实、密度大 | **树体寿命最长**（积田村一株约 65 年，茎周 1.43 m、冠幅 10.2×9.5 m、树高 6.8 m）；**最宜切片**；化州孔庙青云路所植即此品种 |
| **副毛** | 枝梢开张；叶薄色淡 | 果梨形，毛**短、稀** | 果色黑 | 坐果力强、易丰产，可作**授粉树**；药效与价均低于正毛 |

### 5.2 地方株系〔企〕

| 株系 | 特征 |
|---|---|
| 金钱脐 | 花柱脱落处有铜钱大小圆环 |
| 凤尾 | 柱头多不脱落 |
| 红肉 | 生长至中期果瓣汁胞呈红色 |
| 陆福 | 平定镇低坡村陆福村所产，花柱脱落处多皱，果扁球形 |
| 大茶岭 | 平定镇马力村大茶岭村所产，果球形偏小 |
| 无叶翼化橘红 | 叶翼退化或完全退化 |

> 老产区存在"同物异名、一物多名"，植物学性状区分与推广价值仍待考证。

### 5.3 近年良种与种源

- 推广良种：**正尊金毛、正毛红肉**（红峰农场 4 个优良品种）、厚叶正毛。
- 建设**无病毒母本**繁育体系，保障种源纯度。
- 良种覆盖率 98%。

### 5.4 栽培要点（《化橘红种植技术规程》，茂名市 2020 年发布）〔企〕

| 项目 | 要求 |
|---|---|

## 6. 生产流程

### 6.1 药典法定工艺（毛橘红最小必要工序）〔典〕

```
采幼果 → 沸水略烫（杀青/脱青） → 割 5 或 7 瓣
       → 除去果瓤 + 部分白色中果皮 → 压制成形 → 干燥
```

### 6.2 1963 年版药典记载的传统工艺（理解古法的原点）〔典〕

> "将未成熟的果实，先投入沸水中，即捞出，将果皮割成 5–7 瓣，出去果瓤及内面部分白色的中果皮后晒干或焙干，**再以水润透，对折以木板压平，再焙干即得**。"

即古法七步：**烫 → 割 → 去瓤 → 晒/焙 → 回润 → 木板压平 → 复焙**。中间"回润压平"是形成"对折七角"外观的关键，也解释了后来为何必须发明压果机。

### 6.3 现代工厂化流程（八至十二道工序）

| # | 工序 | 设备/方式 | 关键控制点 |
|---|---|---|---|
| 1 | 采摘 | 人工/升降平台 | 5–6 月，按果径与成熟度分级 |
| 2 | 选果分级 | 滚杠式/滚筒式分级机、选果台、色选机 | 按直径分档，决定切瓣规格 |
| 3 | 清洗 | 滚筒/毛辊/气泡清洗机 | 去泥沙，保护绒毛 |
| 4 | **杀青（脱青）** | 沸水烫漂机 / 蒸汽杀青 | 钝化酶、固色、去苦涩、便于割瓣 |
| 5 | **割瓣（雕刻）** | 人工刀 / **七爪切瓣机** | 七等分、切瓣不切透 |
| 6 | **粗去瓤** | 人工铲挖 / **旋挖去囊机** | 保证果皮厚度一致 |
| 7 | **精去瓤** | 人工修整 | 去净白色海绵层 |
| 8 | **压形（压果）** | **液压压果机 / 成型机** | 压成圆柱体，提高切片成型率 |
| 9 | 一次烘干 | 热泵烘房、智能烘房 | 定色定型 |
| 10 | 二次压制 + 二次烘干 | 压果机 + 烘房 | 定型、含水率达标（药典 ≤11%） |
| 11 | **陈化** | 陈化仓（麻袋/陶缸/恒温仓） | "愈陈愈良"，溢价核心 |
| 12 | 切片/包装/赋码/检验 | 切片机、枕式包装机、喷码赋码、HPLC | 柚皮苷 ≥3.5%，一物一码溯源 |

> 官方（化橘红官网）将工艺压缩为六步传播：**摘果 → 脱青 → 雕刻 → 选果烘干 → 压果切片 → 精选包装**。

> 传统七爪流水线（专利文献描述）：**切果 → 粗去瓤 → 精去瓤 → 初步压制 → 一次烘干 → 二次压制 → 二次烘干 → 捆扎包装**。

### 6.4 关键工艺参数与出成率〔政〕〔专〕

| 指标 | 数值 |
|---|---|
| 烘干周期 | 传统土烘房 **7 天**；智能烘房 **4 天** |
| 出成率（整果） | 约 **100 斤鲜果 → 20 斤干果** |
| 出皮率（七爪） | 100 斤鲜果仅得约 **4 斤干皮（4%）** |
| 采摘窗口 | 极短；来不及采的果子长大，**每年约一半鲜果需去瓤处理** |
| 脱苦（深加工） | 柚苷酶 1.5–3 U，45 ℃ 恒温搅拌 2 小时，浓缩后冻干得粉末 |
| 水分 | ≤ 11.0% |
| 总灰分 | ≤ 5.0% |
| 柚皮苷 | ≥ 3.5%（干燥品计） |
| 炮制（饮片） | 除去杂质，洗净，闷润，切丝或块，晒干 |
| GMP 车间流程 | 称量复核 → 净制 → 洗润 → 切制 → 干燥 → 中转包装 → 检验入库 |

## 7. 专用机械装备（重点）

### 7.1 判断标准

**只有化橘红这道工序存在、通用柑橘设备无法替代的，才算"独有"。**
通用设备（清洗、分级、切片、包装、冻干）不计入独有，但产线必需。

### 7.2 五类真正独有的专用装备

#### ① 七爪（五爪）等分切瓣机 —— 最具标识性的专机

| 项 | 内容 |
|---|---|
| 为什么独有 | 通用柑橘分瓣机是"切透分瓣"（分离果肉瓣）；化橘红要求 **切瓣不切透、果蒂相连、七等分、切口外翻**，以便整体去瓤后仍是一张完整果皮 |
| 商品机 | **万顷隆牌七爪化橘红切瓣机**（沧州万顷机械设备有限公司）；1688 挂牌价 **¥78,000/台**；卖点"一台机器替代大量人工""切瓣不切透" |
| 专利 | **CN202210330144《一种化橘红七爪加工装置》**（李银朵，2022-06-25 公开） |
| 核心机构 | 机架 + **半环状 U 形空心壳**（内充液压油）+ 中心**插杆**定心 + 径向多个**圆筒/活塞板/压簧** + 锥形**定心轮** + **齿圈与小齿轮（带单向离合器）** + 竖轴螺纹**滑筒** + 竖直**刀片** + 弧形**齿条**传动 |
| 巧思一：分度 | 小齿轮沿齿圈滚动一圈，经单向离合器带动摩擦盘使果子恰好转 **1/7 周** → 天然七等分；改传动比即得五爪，理论上可任意等分 |
| 巧思二：切深自适应 | 果径大 → 锥形轮外推 → 压迫液压油 → 液压缸顶起平板 → 刀片切深恒定，保证每瓣果皮厚度一致 |
| 巧思三：去瓤标识 | 刀片下端**双弧形槽 + 弹簧切刀**，切口处把果皮向外掰开，为下一道去瓤提供"厚度标识"，可省去精去瓤工序 |
| 现场价值 | 老工艺"开七刀"依赖老师傅眼力（有 79 年刀龄案例）；设备化后单机可替代数人 |

#### ② 旋挖去囊（去瓤）机 —— AI 视觉 + 变径刀具

| 项 | 内容 |
|---|---|
| 为什么独有 | 橘红果小、皮薄、绒毛不能伤，需去净内层海绵瓤而不破皮；通用去核机/挖囊机做不到 |
| 专利 | **CN112106998A / CN213819751U《一种鲜果旋挖去囊装置》**；申请人：**茂名本正化橘红研究院 + 广东石油化工学院**；结构：机架、安装台、安装套、**旋转刀杆**、刀头、**弹性刀片**、驱动板 |
| AI 升级版 | 广东石油化工学院大创项目（入选第十五届国创年会成果展）：**机器视觉 + AI 模型预测胚囊参数**，控制**可伸缩扩张刀具**精准旋挖去囊，替代人工，实现低成本、高效率、低损失率 |
| 一体化方案 | 《**化橘红果分瓣去瓤装置设计**》，《南方农机》2026 年第 5 期：集成**计算机视觉 + 内孔涨紧定位夹具 + 传送机构 + 切割机构 + 去瓤机构 + 激光测距模块**，一次装夹完成分瓣与去瓤 |
| 产业化痛点 | 采摘期短、人工短缺；"每年一半鲜果需去瓤"；人工切开挖瓤速度慢、成本高，直接卡住产能 |

#### ③ 压果机 / 圆柱成型机 —— 化橘红独有的"压形"工序

**这是化橘红区别于所有其他柑橘类药材的核心工序**：把杀青烘干后的圆果压成**圆柱体（压果）**，再切片——成型率高、外观好、售价高。

| 机型 | 技术要点 |
|---|---|
| **CN202220081126《化橘红加工成型机》** | 机架 + **双液压协同**：第一压力机构（2 个**水平液压油缸** + 侧推模 + 后模，两模各开**半圆截面膜槽**合成压料腔）；第二压力机构（**垂直液压油缸** + 上压模，与水平方向**互相垂直**）；**防护栅 + 感应装置（安全光幕）**，手离开才动作；液压油箱 + 油泵 + 智能控制系统。模具内壁**全光滑面**——为的是**不破坏果皮绒毛** |
| **CN201922355516《一种橘红压制设备》**（化州市正源堂化橘红实业有限公司，李海波） | 针对"压完粘模、吹风排不掉"：在侧冲模第一驱动斜面上端再接一段**反向的第二驱动斜面**，驱动轮过拐点时产生**横向振动**使压果自动脱模；成形面光滑护毛；**吹风管排料** |
| 商品机 | "化州橘红**自动压果机**""全自动压果机（带套果机）"；市场价**几万元/台**；配套"**选果机**"；厂家提供上门调试 |
| 传统对照 | 人工"铁板压制、敲打"成圆柱形，费时费力、产能低，且**手指易被碾压受伤**（专利背景自述） |

## 10. 产业现状与市场

### 10.1 产区与组织

- 核心区：化州罗江/鉴江流域丘陵；平定、合江、那务、中垌、官桥等 15 个镇（街道）。
- 传统名村：平定镇**大岭村**（七爪老师傅）、**积田村**（密叶、西洋老树）、**六赠村**（厚叶正毛）。
- 组织形态："公司 + 基地 + 协会 + 橘农"；另有"合作社 + 公司 + 基地 + 农户"（培林橘红合作社，带动 3000 余户、年均增收 3 万元）。

### 10.3 代表主体

化州化橘红药材发展有限公司｜培林橘红种植专业合作社（廖志略，全国人大代表）｜化州市正源堂化橘红实业有限公司｜贡园化橘红｜橘国生物｜深融生态｜广东农垦红峰农场｜化州市华逸中药饮片｜广东化州中药厂制药 等。

### 10.4 价格与等级逻辑

- 鲜果保底收购价 ≥ 10 元/公斤（2022 年起政府引导）。
- 干果按**毛色（金黄/白毛最优）、片形完整度、厚度一致性、树龄、陈化年份**分档。
- 溢价最高：黄毛七爪、老树正毛、陈年货、橘红胎（柚皮苷高）。
- 成本结构关键：出皮率仅 4% → 七爪天然高价；人工去瓤成本占比高 → 机械化是降本主线。

### 10.5 打假与地理标志治理

- 主要问题：广西（陆川）、吴川等地橘红冒充；亳州等地企业擅用"化橘红"商品名；网购假货。
- 识别手段：**绒毛（有/无、长/短、密/稀）+ 柚皮苷检测** 双指标。
- 治理工具：地理标志专用标志、证明商标、"一物一码"溯源、地方立法与司法判例。

## 11. 风险与待解问题（诚实清单）

1. **去瓤自动化是最大卡点**：采摘期短 + 一半鲜果需去瓤 + 人工手感依赖，直接限制产能与标准化。
2. **假冒与外地产区冲击**：需依赖绒毛与柚皮苷双指标；地标标志 + 一物一码是治理抓手。
3. **标准碎片化**：国标、地标、团标、企标并存；2023–2026 团标爆发式增长，存在口径不统一风险。
4. **价格与农户积极性**：鲜果价低会抑制种植意愿；保底收购是政策对冲。
5. **史料与营销话术混杂**："《本草纲目》记载""压 99 下""柚皮苷高 4 倍"等需逐一回到原文与检测报告。
6. **陈化环节几乎无装备**：靠仓储与时间，缺乏客观陈化度判定方法（挥发性成分指纹图谱是方向）。
7. **药食同源后的合规边界**：食品形态扩张快于标准与功能声称规范。
8. **专业人才不足**、**消费认知偏低**（企业方自述的四大瓶颈之一）。

## 12. 结论

1. **本质**：化橘红是"唯一以毛论贵、唯一要压成圆柱再切片、唯一把幼果外皮做成七角星"的岭南道地药材；其价值锚点是**绒毛（品种与产地）+ 柚皮苷（成分）+ 陈化（时间）**。
2. **历史**：可信记载起于明代方志与贡品，清代本草与方志确立药名与"一片值一金"的地位，1963 年进入药典，1977 年独立成条。
3. **产业**：二十年间从 3 万亩、卖原料，走到 14 万亩、126 亿元、二产占 78%、200 余 SKU 的全链格局，制度推力（地标、非遗、药食同源、地方立法、农业文化遗产）是关键变量。
4. **装备**：产业史本质是"**用机器替代'开七刀 + 挖果瓤 + 压 99 下'的手感工艺**"的进化史。七爪切瓣机、压果机、智能烘房已商品化成熟；**旋挖去瓤机（AI 视觉 + 变径刀具）是最后也最值钱的一块拼图**。
5. **建议关注**：去瓤环节的整线集成、绒毛保护型接触件设计、陈化度客观判定、以及地理标志的跨境/跨省维权。
