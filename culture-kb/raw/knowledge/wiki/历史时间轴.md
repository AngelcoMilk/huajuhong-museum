# 历史

## 传说与文献要分开看

| 时段 | 性质 | 内容 |
|---|---|---|
| 南朝宋（420–479） | **传说** | 罗辨仙人种橘于**石龙**（化州古城）州署一带，救治病人；州人建“辨仙门”“华严庵”纪念，楹联“韵事忆当年，橘树千株经手植” |
| 北宋绍圣三年（1096） | 史实+传说 | 苏辙谪化州别驾，“雷州安置”，居所寓堂（后称**苏泽堂**），堂前有橘树；传说“颗橘石粮” |
| 北宋 | **传说** | 范祖禹贬化州，饮石龙井水（井旁橘树）而咳愈——“范公识橘” |
| 明万历（约 1600） | **可信首载** | 《高州府志》物产：“**化州橘红为化州独有**” |
| 清康熙十四年（1675） | 可信 | 《广东通志》称其为粤中“灵奇珍异”“独擅其美者” |
| 清乾隆十三年（1748） | 可信 | 《化州志》：“化州药属……惟橘红最为佳品” |
| 清光绪十四年（1888） | **可信，最常引用** | 彭以孙《化州志》：“化州橘红，治痰症如神，**每片真者值一金**，每年结实，**循例报明上官，至期采摘批制**，即官斯土者亦不易得” |

> 本草序列：李中立《本草原始》“橘红，广东化州者胜” → 张璐《本经逢原》（1695）→ 陈复正《幼幼集成》（1750）正式载“化州橘红” → 赵学敏《本草纲目拾遗》（1751）→ 吴其浚《植物名实图考》（1848）单独立目附图。

## 技艺从哪来：不是家家户户，是“城内几家园”

**决定性证据**（《化州橘红志》转述）：

> “化州橘红亦由野生逐渐转为家种。到了清初，出现了**专事种植**化州橘红的**赖家园、李家园和潘家园**（均在县城宝岭上）。各园均种化州橘红树**数百株**，并总结了一套具体的种植、加工方法和经验。”

更细的考据（周郁成、陈土富，据明清各版《化州志》与族谱）：

> 明清以来真正有史可寻的家族只有**周氏橘园、潘家园、李家园、苏家园、赖家园**——**五大橘红园，都在化州城内**。

| 园 | 位置 |
|---|---|
| 赖家园 | 城西**宝山之麓**，鼓楼→柳公桥→杏花村水井往上，门头有园名 |
| 李家园 | 宝岭东麓，李氏宗祠旁；明成化年间起，清初李作龙祖辈迁此 |
| 潘家园、陈家园 | 宝岭上，清末民初停种 |
| 苏家园 / 周氏橘园 | 城内，与苏泽堂系统相关 |

**结论**：起源是“点”（城内一株），成熟于“园”（家族专营），普及于“户”（1980s 后），体系化于“政”（2006 后）。

## 贡品：半官营，不是自由市场

光绪《化州志》那套流程拆开看：

1. **报明上官** —— 产量要上报
2. **至期采摘批制** —— 采摘加工须经批准
3. **官斯土者亦不易得** —— 连地方官都难私得
4. 等级制：**苏泽堂 > 清风楼 > 红树**
5. 产地限定：“**亦署内城内者宜用**”

## 规模曲线（最能量化的一段）

| 时期 | 种植面积 | 备注 |
|---|---|---|
| 清代中叶 | **300 多亩（约 1 万余棵）** | 集中在城内几园 |
| 1949 | **30 多亩（约 2000 余棵）** | 战乱 +“当局只顾索取，不问生产”，缩水约 80% |
| 1950s | 政府拨专款复苏旧橘园、辟新产区 | — |
| 1962 | 成立**县橘红生产办公室**，委托**药材公司**统管生产、加工、收购、销售 | 第一次真正组织化 |
| 70 年代初 | 3000 多亩 | — |
| 1985 | 8500 亩（约 17 万棵） | — |
| 2005 前后 | 3 万余亩 | — |
| 2024 | **13.26 万亩** | — |
| 2026 | **14.3 万亩** | 年产鲜果 7.6 万吨 |

## 组织形态演变

| 时期 | 形态 | 程度 |
|---|---|---|
| 南朝—宋 | 州署/寺庵旁孤株 | 无 |
| 明—清初 | **家族园圃（五大园）** | 中（家族内专业、对外秘传） |
| 明—清 | **贡品管控** | 中高（准官营） |
| 清末—1949 | 崩坏，退为残株 | 低 |
| 1950s—80s | 县办公室 + 药材公司统购 + 制品厂 | 高（单位化） |
| 1980s—2000s | 分户承包 + 零星企业 | 低（分散） |
| 2006 至今 | 地标 + 协会 + 产业园 + 合作社 + 立法 | 最高 |

> 1982 年**赖家园扩建为化州县赖家园橘红制品厂**，1987 年 1 月改名**化州中药厂**（职工 20→100 多人）——家族字号被“单位化”的典型链条。

## 传承谱系（李氏）

| 代 | 人物 | 事 |
|---|---|---|
| 明成化年间起 | 李氏家族 | 在化州种植、炮制化橘红 |
| 清初 | 李作龙祖辈 | 迁宝岭东麓，居李氏宗祠，经营渐兴 |
| — | 德胜公 | 化橘红工艺“初成”，“李家园”名声渐响 |
| — | **李智昌** | 整理祖传工艺成体系；**1922 年以“李家园”名义参加广东第二次农产品展览会，获最优等奖** |
| 第 24 代 | **李锋**（1958 生） | 省级非遗代表性传承人；2005 建 GMP 公司；2011 建化州橘红博物馆；著《化橘红图志》40 余万字；2012 推动列入《美国药典》 |
| 新一代 | **廖志略**（90 后） | 化州市培林橘红种植专业合作社社长、全国人大代表；推动药食同源入目录；带动 3000 多户 |

**李氏家训**：“用心把住金色火，细心烤出精品药。”

> 秘传也是证据：李锋说“祖父本来不希望她把化橘红的制作工艺传给外人”，直到 2016–2020 才做“五年计划”每年 4 次公开培训。**秘传 = 非普及。**

## 现代制度节点

| 年份 | 事件 |
|---|---|
| 2006 | 国家地理标志产品保护（原质检总局 **2006 年第 219 号公告**，12 月 31 日） |
| 2009 | 化州获“**中国化橘红之乡**”；化府〔2009〕40 号管理办法 |
| 2012 | **化橘红中药文化入选第四批广东省省级非物质文化遗产** |
| 2013 | 获准注册地理标志证明商标 |
| 2021 | 入选**国家地理标志产品保护示范区**（筹建） |
| 2023 | 茂名市化橘红产业协会成立（3 月 20 日） |
| **2024.5.1** | **《茂名市化橘红保护发展条例》施行**（七章五十三条） |
| **2024.8.26** | 国家卫健委 + 市场监管总局公告，化橘红等 4 种物质纳入**食药物质目录**（药食同源） |
| 2025 | 全产业链产值 **126 亿元** |
| **2026.10** | **“广东化州化橘红种植系统”入选第八批中国重要农业文化遗产** |
